O · Norme

Une base de données qui suit une norme

  • L'ISO 28258, Qualité du sol : échange numérique de données relatives au sol, dit de quoi sont faites les données de sol et comment les pièces s'articulent.
  • Elle s'appuie sur le modèle général de l'ISO pour les observations et mesures : chaque valeur appartient à une chose observée, une propriété, une procédure et une unité.
  • Les tables d'OpenNSIS dérivent de la mise en œuvre ouverte de l'ISRIC de ce modèle, et les listes de codes viennent de GloSIS.
  • Résultat : les données stockées dans un pays ont déjà la même forme que celles de tous les autres nœuds.

La norme n'est pas un format de rapport.
C'est la forme des tables.

Schéma soil_data, dérivé de github.com/ISRICWorldSoil/iso-28258 (licence MIT ; de Sousa et al., 2023).

Les choses observées de l'ISO 28258, de haut en bas. Tout le reste de la base de données pointe vers l'une d'elles.

Un élément est un horizon ou une couche, avec ses profondeurs supérieure et inférieure. Un specimen est l'échantillon qui en est prélevé.

Un projet possède ses parcelles : les règles de partage se fixent donc projet par projet.

Pour ce qui est décrit, non mesuré : occupation du sol, matériau parental, drainage, couleur, structure, classification.

Un résultat n'est jamais du texte libre. C'est une catégorie d'une liste de codes : deux pédologues écrivent la même chose de la même façon.

Quatre tables de résultats, une par niveau : une description peut porter sur la parcelle, sa surface, le profil ou un seul horizon.

Un nombre est stocké une seule fois, sur un échantillon, et toujours avec sa propriété, sa procédure de laboratoire et son unité.

Chaque combinaison porte l'intervalle des valeurs plausibles : c'est ce qui permet au contrôle du téléversement de refuser un pH de 62.

40 conversions d'unités permettent aux données d'arriver dans l'unité du laboratoire et d'être stockées dans l'unité convenue.

Le spectre lui-même est conservé, lié à l'échantillon sur lequel il a été lu et à l'instrument qui l'a lu.

Une valeur prédite à partir de spectres est un résultat comme un autre, mais elle nomme le modèle qui l'a produite.

Les valeurs prédites et celles du laboratoire pour une même propriété partagent un code d'observation : on peut donc les comparer.

La carte des sols classique : des polygones (unités cartographiques) tracés à une échelle déclarée, chacun avec sa place dans la légende.

Une unité cartographique peut contenir plusieurs types de sol, chacun avec sa part en pour cent.

Les deux se rattachent à l'épine rouge : les profils qui représentent une unité ou sont typiques d'un type de sol.

Un mapset est un produit cartographique décrit comme une fiche ISO 19115 ; ses couches sont les fichiers raster, par profondeur et statistique.

Le catalogue, le WMS et la visionneuse sont tous générés à partir de ces lignes : ils ne peuvent pas se contredire.

Les personnes et les organisations sont saisies une fois et reçoivent un rôle par projet : propriétaire, auteur, point de contact.

Toute colonne de texte de toute table peut recevoir une traduction par langue, sans modifier la table elle-même.

En place dans le schéma et pas encore remplie ; aujourd'hui, les six langues de l'interface sont traduites dans l'application.

R · En pratique

Un nombre, suivi à travers les tables

# dans le tableur : une cellule, « 6.2 »
project          Inventaire national des sols
 plot            P-0412  point, date
  profile        P-0412-1
   element       0 à 30 cm  couche
    specimen     LAB-88231
     observation  PH · PHH2O_RATIO1-2.5 · pH
     result_num   value = 6.2
  • Six lignes de l'épine rouge disent d'où vient le nombre.
  • Une ligne violette dit ce qu'il est : pH, dans l'eau à 1:2,5. Une autre contient le nombre.
  • Le téléversement fait cela pour chaque cellule, après l'avoir vérifiée par rapport aux listes.
Les noms et les valeurs sont donnés à titre d'illustration ; le code de l'observation est le vrai.

R · En pratique

Ce que le modèle apporte

Contrôles à l'entrée

Une valeur hors de l'intervalle de son observation, ou une catégorie absente de la liste, est signalée avant d'être stockée.

Comparable par construction

Deux projets ayant mesuré le carbone organique par des méthodes différentes restent distincts, et ceux qui ont utilisé la même peuvent être regroupés.

Prêt pour la fédération

Les codes sont ceux de GloSIS : ce qu'un nœud répond au Discovery Hub ne demande aucune conversion.

La qualité suit la méthode

L'incertitude et les limites de détection sont conservées par observation, et les résultats sous la limite de détection sont stockés comme tels.
