A situação que todos reconhecemos

  • O levantamento de 2014 vive num único portátil — e o dono mudou de emprego.
  • Um distrito é amostrado duas vezes, porque ninguém sabia que a primeira campanha existia.
  • Uma coluna da folha de cálculo diz P — fósforo? Total ou disponível? Que método, que unidade? Já não há a quem perguntar.
  • O mapa final do consultor é um PDF. Os dados que lhe deram origem nunca foram entregues.

«Dados sem metadados
morrem com o disco rígido
em que vivem.»

Tudo nesta apresentação existe para tornar impossível cada uma destas situações.

Cinco horizontes, um perfil

Tal como num perfil de solo, os temas de hoje sobrepõem-se: cada horizonte assenta no que está por baixo — até à rocha-mãe.

O · OGC

OGC: concordar numa linguagem comum

  • O Open Geospatial Consortium — um consórcio internacional onde organismos públicos, produtores de software e investigadores acordam normas abertas para a informação geográfica.
  • Trabalha lado a lado com o ISO/TC 211 — as normas de serviços do OGC e as normas de dados da ISO formam uma só família.
  • Uma norma é um livro de regras público: qualquer pessoa pode implementá-la, em qualquer software, sem autorização nem taxas.
  • Tudo nesta apresentação — descrever dados, servir mapas, pesquisar catálogos, federar países — existe como uma destas normas.

A · Metadados espaciais

O que são

Os metadados são informação estruturada sobre um conjunto de dados — tudo o que é preciso saber antes de confiar nele.

  • Identificação — o que foi medido, onde, quando, por quem
  • Referência espacial — sistema de coordenadas, resolução, extensão
  • Método e linhagem — como se produziram os valores, a partir de que fontes
  • Condições — licença, restrições, contacto para dúvidas

A · Metadados espaciais

Porque importam

  • Descoberta — um conjunto de dados que ninguém consegue encontrar é como se não existisse.
  • Adequação ao uso — um mapa de 250 m de 2009 serve para uma decisão de campo em 2026? Só os metadados o podem dizer.
  • Memória institucional — as pessoas mudam de funções; dados bem descritos sobrevivem a quem os produziu.
  • Sem esforço duplicado — os levantamentos são caros; saber o que existe evita pagá-los duas vezes.
  • Clareza legal — a licença e as restrições fazem parte do registo, não da tradição oral.

«Os metadados são uma carta
ao colega que
ainda não conhecemos.»

A · Metadados espaciais

O que existe

Uma norma

A ISO 19115 define que campos descrevem os dados geográficos; a ISO 19139 define o XML que os transporta. Um vocabulário partilhado em todo o mundo.

Catálogos

Software que guarda registos e responde a pesquisas: pyCSW, GeoNetwork. Quadros regionais como o INSPIRE fazem da sua publicação uma obrigação legal na Europa.

No OpenNSIS

O registo ISO 19115 é gerado automaticamente a partir do formulário preenchido ao registar um mapa — e publicado no catálogo integrado, com uma página pública de pesquisa. Sem editar XML, nunca.

O formulário de metadados, o catálogo e a página Catálogo são três vistas do mesmo registo na base de dados.

B · Serviços web

O que são

  • Dados disponibilizados por HTTP segundo regras acordadas: uma forma fixa de perguntar, uma forma fixa de responder — definidas pelas normas OGC.
  • O cliente nunca precisa de saber que software está por trás do URL — apenas a norma.
  • Em vez de enviar ficheiros por e-mail, partilha-se um endereço vivo: sempre a versão atual, diretamente da fonte.
http://5.223.62.255:8027/mapserver?
  map=/etc/mapserver/MZ-SOILFER-TEXTCLAY-2026-0-30-MEAN.map
  &SERVICE=WMS&VERSION=1.3.0&REQUEST=GetMap
  &LAYERS=MZ-SOILFER-TEXTCLAY-2026-0-30-MEAN&STYLES=
  &CRS=EPSG:4326&BBOX=-27,30,-10,41
  &WIDTH=520&HEIGHT=800&FORMAT=image/png
→ uma imagem de mapa, de qualquer servidor para qualquer cliente — experimente ao vivo

B · Serviços web

Porque importam: publicar uma vez, usar em qualquer lado

  • Interoperabilidade — a mesma camada WMS abre no QGIS, no ArcGIS, numa página web e num script Python, sem alterações.
  • Sem dependência de fornecedor — troque o software do servidor e todos os clientes continuam a funcionar: a interface é a norma, não o produto.
  • Uma só fonte de referência — os colegas usam o serviço em vez de trocarem cópias por e-mail, logo desatualizadas.
  • Pronto para federar — sistemas que falam as mesmas normas ligam-se mais tarde sem redesenho.

B · Serviços web

O que existe

Servidores

MapServer e GeoServer publicam WMS/WFS/WCS; o pyCSW publica o catálogo. Todos livres e de código aberto, todos comprovados ao longo de décadas.

Clientes

Qualquer SIG que se preze fala OGC de origem — no computador (QGIS, ArcGIS), em bibliotecas web (OpenLayers, Leaflet) e em scripts (Python owslib, R).

No OpenNSIS

Cada raster publicado é automaticamente uma camada WMS (MapServer), em mosaicos com cache; cada registo de metadados é servido por CSW (pyCSW) — as normas trabalham nos bastidores.

O mapa que se vê no navegador é, ele próprio, um cliente WMS — a consumir o serviço do próprio sistema.

C · GloSIS

GloSIS: uma federação, não um armazém

  • O Sistema Global de Informação de Solos da Parceria Global do Solo (GSP) da FAO.
  • Não é uma base de dados central: é uma rede de sistemas nacionais que permanecem em servidores nacionais, sob mandato nacional.
  • Cada país expõe os seus dados de solo através de interfaces normalizadas; o nível global liga-se a elas.
  • A soberania dos dados faz parte do desenho, não é um acrescento tardio — os países decidem o que é partilhado e ficam com o original.

C · GloSIS

A linguagem comum dos dados de solo

  • Listas de códigos harmonizadas — um identificador acordado por propriedade do solo e por procedimento laboratorial, retirado da ontologia web do GloSIS.
  • «pH em água, 1:2,5» significa exatamente o mesmo em Maputo, Jacarta e Roma — os valores tornam-se comparáveis, não apenas colecionáveis.
  • Produtos globais como o GSOCmap são compilados a partir de dados nacionais — a qualidade ao nível nacional é o que o mundo acaba por ver.
  • Um sistema nacional que fala GloSIS já nasce ligado: sem projetos de conversão mais tarde.
# a mesma medição, em todo o lado
propriedade:   phH2o
procedimento:  phH2o-1:2.5
unidade:       pH
profundidade:  0–30 cm

R · OpenNSIS

OpenNSIS: a rocha-mãe

  • Um Sistema Nacional de Informação de Solos de código aberto, desenvolvido pela FAO para — e com — as instituições nacionais de solos.
  • Licença Apache 2.0: o código, o esquema da base de dados, os scripts de instalação e a documentação são públicos. Não é precisa nenhuma entrega — já é seu.
  • Instala-se num servidor Linux comum com um comando; atualiza-se com mais um.

R · OpenNSIS

O que oferece

Mapas na web

Visualizador público: rasters de solo em mosaicos com cache, perfis com observações, limites.

Sítio web público

Página inicial, Sobre, Equipa, Contacto, Notícias, Catálogo e Estatísticas — ativo de origem.

ETL de perfis de solo

Carregamento de CSV, mapeamento de colunas, validação por regras, ingestão num clique.

Laboratório (LIMS)

Amostras aprovadas vêm diretamente do LIMS, com incerteza e limites de deteção.

Calculadora de rasters

Mapas de aptidão a partir de receitas de limiares sobre rasters publicados.

Catálogo de metadados

Registos ISO 19115/19139 automáticos, servidos pelo pyCSW e numa página pública de pesquisa.

Desenhos de amostragem

Método SoilFER em três etapas: desenhe a região no mapa e publique o desenho como camada.

Federação GloSIS

Ligação ao GloSIS Discovery Hub num clique — partilha nas condições do país.

Controlo da partilha de dados

Opções por projeto, desfocagem espacial, limites públicos.

Divisões administrativas

Camadas de limites com estilo, a partir de GeoJSON, Shapefile, GeoPackage ou KML.
