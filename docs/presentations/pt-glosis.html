O · Porquê

Uma pergunta simples, uma resposta difícil

  • «Quanto carbono orgânico há nos solos da África Austral?» — a resposta está espalhada por dezenas de instituições.
  • Cada país mede com métodos, unidades e profundidades diferentes.
  • Muitos dados existem apenas em relatórios, folhas de cálculo e discos pessoais.
  • Sem dados nacionais acessíveis, os mapas globais fazem-se sobre os países, não com os países.

«Os solos não conhecem fronteiras.
Os dados de solo,
infelizmente, sim.»

O · Porquê

Duas maneiras de juntar dados

Armazém central

Os países enviam cópias dos seus dados para uma base de dados única.

A cópia envelhece no dia seguinte.
Quem decide o acesso é quem guarda.
O país deixa de saber quem usa o quê.

Federação

Os dados ficam no país; cada sistema nacional responde a pedidos normalizados.

Sempre a versão atual, diretamente da fonte.
O país decide o que publica — e pode mudar de ideias.
Exige uma coisa: falar a mesma linguagem.

O GloSIS escolheu a federação. O resto desta apresentação é sobre essa «mesma linguagem».

O · Porquê

Porque interessa a Moçambique

  • Visibilidade — os dados nacionais passam a ser encontrados por quem planeia, investiga e financia.
  • Voz própria — os produtos globais passam a usar os números de Moçambique, validados em Moçambique.
  • Comparabilidade — os mesmos códigos que os países vizinhos e os parceiros.
  • Menos duplicação — saber o que já existe antes de pagar um novo levantamento.

A · O que é

O GloSIS em quatro frases

  • O Sistema Global de Informação de Solos (Global Soil Information System) da Parceria Global do Solo (GSP) da FAO.
  • Um sistema descentralizado: uma federação de nós nacionais ou regionais, cada um um sistema de informação de solos.
  • Cada nó publica os seus dados segundo normas de intercâmbio acordadas.
  • Os dados continuam a pertencer aos países; a GSP ajuda cada país a construir o seu sistema.

A · O que é

A política de dados de solo da GSP

  • Aprovada pela Assembleia Plenária da GSP.
  • Respeita os direitos de propriedade existentes sobre os dados partilhados.
  • Aceita as restrições herdadas das políticas nacionais de dados.
  • Metadados abertos por defeito — mesmo quando os dados têm condições de acesso.
  • Aplica-se também a quem usa os dados e cria produtos derivados.

Participar no GloSIS
não é entregar os dados —
é dizer que existem.

Resumo; o texto em vigor está nos documentos da GSP: fao.org/global-soil-partnership

Produtos globais feitos com os países

Mapa global dos solos afetados por sais, com a mesma abordagem.

Abordagem conduzida pelos países: cada país produz o seu mapa; a GSP harmoniza e junta. A qualidade ao nível nacional é o que o mundo acaba por ver.

B · Linguagem

Uma ontologia para dizer a mesma coisa

  • A ontologia web do GloSIS: um modelo de dados publicado na web, que reutiliza normas e ontologias existentes.
  • Assenta na ISO 28258 — a norma para o intercâmbio digital de dados de solo.
  • As listas de códigos são públicas e mantidas em aberto.
  • O OpenNSIS usa o mesmo modelo e as mesmas listas na sua base de dados.

B · Linguagem

Um valor só faz sentido com três etiquetas

# «6,2» não diz nada. Isto diz:
propriedade:   pH
procedimento:  em água, 1:2,5
unidade:       pH
profundidade:  0–30 cm

Cada etiqueta é um código de uma lista acordada — o mesmo em Maputo, Jacarta e Roma.

B · Linguagem

O que a harmonização dá em troca

  • Comparar projetos, laboratórios e décadas diferentes dentro do país.
  • Juntar os dados de vários fornecedores num só mapa nacional.
  • Validar à entrada: regras por propriedade, limites do país, unidades convertidas na ingestão.
  • Nascer ligado: o que entra harmonizado no SIS nacional já fala GloSIS — sem conversões mais tarde.

Harmonizar não é
mudar os dados —
é descrevê-los da mesma maneira.

C · Ligação

O Discovery Hub em três verbos

Recolher

Periodicamente, lê o catálogo e o resumo de propriedades de cada nó. Nada de dados brutos.

Verificar

Testa se os nós e as camadas de mapa estão vivos. O que deixa de responder sai dos resultados.

Encontrar

Desenha-se uma área no mapa; depois filtra-se por palavra-chave ou por propriedade do solo.

Também aceita catálogos CSW comuns (GeoNetwork, pyCSW…): só normas, nada específico de um fornecedor. Endereço de trabalho: http://5.223.62.255:8083/

R · Moçambique

Ligar: um clique no painel de administração

1 · Ligar

O nó ativa a federação, gera o seu token e regista-se no hub.

2 · Aprovação

O hub confirma que o endereço responde; o seu administrador aprova o pedido.

3 · Desligar

A qualquer momento: os pedidos passam a ser recusados. Nada é apagado.

R · Moçambique

O país decide o que é partilhado

  • A federação recebe exatamente o que um visitante vê no SIS: os perfis publicados, com os mesmos limites e a mesma desfocagem.
  • O controlo é por projeto: publicar ou não, só localizações, limite de perfis, desfocagem em metros.
  • Os mapas seguem pelo catálogo público e pelo WMS.
  • A API de federação lê a base de dados com um utilizador só de leitura, limitado a três vistas.

Não há uma «cópia para o GloSIS».
Há uma janela — e o país segura o estore.

Mais na sessão seguinte: partilha de dados e licenças.
